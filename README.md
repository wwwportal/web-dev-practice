# web-dev-practice

A collection of small web development exercises from an introductory web dev course, kept together since none is substantial enough to stand alone.

- `WebFundamentalsQA` — written answers to web fundamentals questions (client-server model, DNS resolution, HTTP, URLs, response codes)
- `MyFirstWebPage` — a basic HTML page reviewing a web development textbook
- `MultimediaPage` — an HTML/CSS page embedding images, audio, and video
- `LengthConverter` — a Bootstrap + jQuery page converting between inches and centimeters
- `PHPBasics` — small PHP exercises (hello world, variables, string/number operations)
- `PHPPortfolioPage` — a PHP page using `include` for a shared header/footer, displaying student info and date/math functions. Its nav links point to `Lab2/Lab3/Lab4` subfolders from the original course layout, which don't exist here since each exercise now lives in its own top-level folder — left as-is rather than rewritten.
- `LoopsAndFunctions` — small PHP exercises covering loops, functions, and conditionals
- `LoopsFunctionsPortfolio` — a fuller PHP portfolio page (shared header/footer/menu) demonstrating loops, patterns, even/odd checks, and random numbers
- `Calculator` — a PHP calculator (add/subtract/multiply/divide/exponent) that also reports whether the result is prime and odd/even, plus array and object exercise pages sharing the same header/menu/footer
- `MySQLCrud` — PHP/PDO CRUD scripts (insert/select/update/delete) against a MySQL database. `MySQLConnectionInfo.php` is gitignored — copy `MySQLConnectionInfo.php.example` and fill in your own credentials
- `JSExercises` — small JavaScript exercises (area calculators, factorial, Fibonacci)
- `ArtistGallery` — a PHP artist/painting gallery display (an earlier, thinner version of the ideas later built out fully in [PaintingPortal](https://github.com/wwwportal/PaintingPortal); image assets omitted here since they're the same set used there)
- `AngularJSAndBootstrapSamples` — course-provided AngularJS and Bootstrap sample pages
- `JavaScriptExamples` — course-provided JavaScript examples: GCD, hello world, even/odd tester, and two versions of a factorial calculator
- `PHPOOPExamples` — course-provided PHP OOP examples covering arrays, encapsulation, inheritance, and polymorphism (an `Art`/`Artist` class hierarchy)
- `MultimediaEmbedExample` — course-provided example embedding an image, audio, and video into one page
- `PHPIncludeExample` — course-provided example of PHP's `include` pattern for a shared header/footer
