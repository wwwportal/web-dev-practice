2. Define Client-Server model of communications.

The Client-Server model technically synonymous with the Web. It defines a system with a minimum of two agents. The client makes requests and receives responses from the server in the form of response codes.

8. What is the difference between a static and a dynamic web site?

A static web site displays some HTML and perhaps some additional content such as images, but does not run programs on the server. Naturally, dynamic web sites are the opposite. They contain practically all the elements of a static website, but they also run programs on the server. These programs can interact with other resources on the server or services on other computers.

9. Why do we need Domain Name System (DNS)?

We need DNS to make the web user-friendly. Specifically, we use DNS to convert IP addresses to domain names written in english (or other natural languages), which can be easily understood.

10. Describe in detail the process of DNS address resolution?

1. Client makes request for domain
2. Client computer checks local DNS Cache
3. If requested domain is not in the local cache, the computer requests the IP address for the domain from its primary DNS server
4. If the primary DNS Server doesn’t have a record for the requested domain in its cache, it sends out the request to the Root Name Server
5. The Root Name Server returns the address of the relevant Top-Level Domain (TLD) Server.
6. The DNS Server requests the DNS record information from the provided TLD Server.
7. The TLD Name Server returns with the IP addresses of the Authoritative DNS Servers for the requested domain.
8. The DNS Server requests the IP address for the originally requested domain from one of the site’s Authoritative DNS Servers.
9. The DNS Server returns the IP address of the requested domain.
10. The client computer can finally make its request of the domain.

14. What is the function (purpose) of Hypertext Transfer Protocol (HTTP)?

HTTP establishes a TCP connection on port 80. The server waits for the requests and then responds with a:
- Headers
- Response code
- optional message

19. Define HTTP response codes. Write down the meaning of the following response codes.

200: OK: successful request.
301: Moved Permanently: requested sources has permanently moved.
304: Not Modified: resource on server is the same version as the one in the client cache.
401: Unauthorized: requested resource is protected and requires credentials to be accessed.
404: Not Found: requested resource was not found.
414: Request URI too long: too much data is trying to be submitted via URL
500: Internal Server Error: server has encountered an error.
